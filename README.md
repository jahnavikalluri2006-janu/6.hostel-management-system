# Hostel HQ

A lightweight Hostel Management System built with HTML, CSS, JavaScript, Node.js, and Express.js.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000` in your browser.

## Included workflows

- Dashboard with occupancy, bed availability, fee collection, activity, and block summaries
- Student registration with room assignment
- Room and bed availability view
- Fee payment ledger with payment recording
- Searchable student directory
- Printable monthly reports

The demo uses in-memory data so it is easy to run locally. Restarting the server resets the sample data.
